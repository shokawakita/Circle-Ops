# 共同主催と利益分配のルール（C型）

> 一般的な情報の整理であり、法的・税務的助言ではありません。
> 実際に金銭の分配を始める前に、税理士または最寄りの税務署・商工会議所の無料相談で確認してください。

## 1. お金の渡し方は4種類しかない

主催メンバーに利益からお金を渡すとき、法律上の扱いは次のいずれかに分類されます。
**名目（「謝礼」「お手伝い代」）ではなく、実態で判断されます。**

| 扱い | 成立する条件 | 起きること |
|---|---|---|
| **給与**（雇用） | 指揮命令下で労務を提供し、その対価を受け取る | 労基法・最低賃金の適用、源泉徴収義務、労災。**これは避けたい** |
| **外注費**（業務委託） | 独立した立場で、成果に対して報酬を受け取る | 受け取る側の事業所得／雑所得。実態が伴わないと給与認定される |
| **利益分配**（共同事業） | 各自が出資（金銭または労務）し、共同の事業の損益を分け合う | 組合には課税されず、各自に直接帰属。**C型の本命** |
| **贈与** | 対価性のない無償の供与 | 事業の分配としては成立しない。実態としてはまず使えない |

C型は3番目、**民法上の任意組合（民法667条）またはそれに準じた共同事業**として設計します。

---

## 2. C型の設計は2通り。まずは C-1 から

### C-1：回ごとの独立採算（推奨・最もシンプル）

**そもそも「支給」を発生させない**のが、最も安全で揉めない形です。

- 各メンバーが、自分の企画の**主催者本人**になる
- 募集も自分名義で出す。サークル名は共通ブランドとして使用を許諾する
- その回の売上はその人のもの。会場費・材料費もその人が払う
- 共通経費（SNS運用、備品、保険、決済手数料）として、粗利の一定率をサークル本体に納める

これなら、誰かが誰かに報酬を「支給」する場面がありません。
各自が自分の事業の売上を得ているだけなので、**雇用にも外注にもなりません。**

```
売上       60,000円  （20名 × 3,000円）
− 原価     30,000円  （会場費）
─────────────────────
= 粗利     30,000円
− 本体納付  3,000円  （粗利の10%）
─────────────────────
主催者の取り分 27,000円  ← 主催者自身の売上
```

### C-2：共同で1つの事業として運営し、期末に分配（任意組合）

規模が大きくなり、1回のイベントを複数人で作るようになったらこちら。
**組合契約書を必ず書面で作ります**（口頭でも成立しますが、揉めたときに何も残りません）。

契約書に定めること:

1. 事業の内容と名称
2. 組合員（誰が）
3. 出資（金銭でも**労務でも可**。労務出資を明記できるのがこの形式の利点）
4. **損益の分配割合** — 出資割合によらず契約で自由に定められる（民法674条）
5. 業務執行者（誰が決めるか）
6. 加入・脱退の手続きと、脱退時の清算
7. 解散事由と残余財産の分配

**課税：組合自体には課税されず、損益は各組合員に直接帰属します（パススルー課税）。**
各自が自分の所得として申告します。分配は「報酬の支払い」ではないため、源泉徴収は不要です。

**注意：任意組合は各組合員が無限責任を負います。**利益だけでなく損失も分配されます。

## 3. 給与と判定されないための5つの条件

労働者性は次の要素で総合判断されます。C型はこれを全部クリアします。

| 判断要素 | 給与になる形 | C型（セーフ） |
|---|---|---|
| 依頼を断れるか | 断れない／シフトを割り当てられる | 自分の企画なので断るも何もない |
| 指揮監督 | 時間・場所・進め方を指示される | 自分が仕切る |
| 報酬の性質 | 時間に比例（時給・日当） | その回の**事業の成果**（粗利）に連動 |
| 事業者性 | 費用を負担しない | 自分で会場費・材料費を負担する |
| 専属性 | 他の活動を制限される | 制限しない |

### 逆に、これをやると給与認定されます

- ❌ 運営に「時給1,500円」で払う
- ❌ 毎月固定額を払う
- ❌ 出席を義務化してシフトを組み、その対価を払う
- ❌ 契約書に「業務委託」と書いても、実態が上記なら**給与**

## 4. 税務まわりで先に押さえること

### 受け取る側（主催メンバー）

- **給与所得者の場合、この収入を含む副業の所得が年20万円を超えると確定申告が必要です**
- これは**分配を始める前に必ず本人に伝える**こと。後から言うと確実に揉めます
- 本業の就業規則で副業が制限されていないかも、本人に確認してもらう

### 支払う側（本体・代表）

- 個人事業主で、誰にも給与を払っていない場合、原則として源泉徴収義務者に該当しません
- ただし**法人化すると源泉徴収義務者になります**
- デザイン料・原稿料など一部の報酬は源泉徴収の対象になるため、SNS画像制作などを外注するときは別途確認が必要
- 消費税は、双方の課税売上が1,000万円以下なら当面問題になりません

### 共通

- **現金手渡しにしない。必ず振込にする。**記録が残ることが双方を守ります
- 誰にいくら、いつ、何の名目で払ったかの台帳を `finance/ledger.csv` に残す

## 6. 書面にすること

A4で1〜2枚の**「共同主催に関する覚書」**を作り、参加する人全員と交わします。
契約書というより「先に決めておいたことの確認書」です。含める内容:

- サークル名（ブランド）の使用を許諾すること、その帰属は代表にあること
- 分配ルール（上記5の表の内容）
- 赤字が出た場合の負担
- 各自が自分の税務申告を行うこと
- 参加者の個人情報を持ち出さないこと
- 脱退はいつでも自由であること、脱退時の精算方法

> 雛形が必要なら Claude に「共同主催の覚書を作って」と依頼してください。
> ただし実際に使う前に、一度は専門家に見てもらうことを推奨します。

## 7. レーベル型への移行（現在の方針）

1000人規模の実績があるため、C型を長く続けず**レーベル型（ハウス・オブ・ブランズ）**へ進みます。
詳細は `docs/vol3-brand-house.html` を参照。

```
Lv.1 当日サポート     無報酬＋参加費免除              ← A型
Lv.2 共同主催         本体に売上、粗利を役割で分配     ← C型（練習台。1〜3回で次へ）
Lv.3 レーベル主催     自分名義で開催・自分で集金       ← 本命
                      本体へブランド使用料を支払う
Lv.4 独立             卒業 or ライセンス継続
```

### 移行の最短路：クローズ会を練習台にする

すでに不定期で開催しているクローズ会は、**Lv.2（共同主催）の練習台として理想的**。
参加者が既知なので失敗コストが低く、公開イベントをいきなり任せる必要がない。
最初の1人はここで育てる。

### Lv.3 の要点

- **各主催者が自分で集金する。**本体が集めて配ると「本体→主催者への支払い」になり、
  給与・外注の議論に戻ってしまう。本体は受け取る側に徹する
- 手数料は**粗利の10〜20%**。逓減方式（開始20% → 通算10回で15% → 独立準備で10%）
- **手数料は収益の柱ではない。**1回の粗利8,000円なら15%で1,200円。役割は
  ①主催者の本気度のフィルター ②ブランド・集客基盤の維持費 ③「これは事業だ」という共通認識
- 収益の柱は**横断メンバーシップ**。手数料の8倍以上になる（`docs/vol3-brand-house.html` Section 07）
- 新しい主催者には**本体と食い合わない別フォーマット**を持たせる（ボドゲ以外）
- 手数料はブランド使用・集客導線・テンプレ・保険・バックアップの対価であり、労務の対価ではない
- **競業避止義務は課さない。**禁止するのはブランド名の無断使用と参加者名簿の持ち出しのみ
- 参加費の額を強制しない、他所での活動を禁止しない（独占禁止法上の配慮）
