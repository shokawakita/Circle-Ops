# circle-ops

神奈川・東京を中心に活動する独立サークルの運営リポジトリ。
イベントの企画から告知・当日運営・収支・振り返り・発信までを、Claude Code から回すためのワークスペースです。

## 使い方

Claude Code でこのディレクトリを開き、以下のコマンドを使います。

| コマンド | やること |
|---|---|
| `/event-new` | 企画から募集文・当日台本・収支シミュレーションまで一括生成 |
| `/event-close` | 開催後の締め。収支確定・振り返り・レポ記事の下書き |
| `/sns-week` | 週次のSNS投稿カレンダーを7日分まとめて作成 |
| `/kpi-monthly` | 月次サマリと収支レポート |

イベント作成の自動化プラン（提案中）は `docs/automation-plan.md` にあります。

`CLAUDE.md` は Claude が常に読む前提ファイルです。ここを整えるほど出力の精度が上がります。

## ディレクトリ

```
brand/      コンセプト・トンマナ・参加規約。すべての文章の元になる
venues/     会場台帳。原価計算と会場選定の元データ
events/     1イベント1ディレクトリ。_template/ を複製して使う
finance/    収支台帳と、共同主催の利益分配ルール
docs/       立ち上げ資料（Vol.1〜Vol.3）と自動化プラン
```

## 最重要の運用ルール

**参加者の個人情報をこのリポジトリに入れないこと。**
扱ってよいのはニックネーム・参加回数・写真掲載可否まで。
本名・連絡先・住所・勤務先は申込フォーム側に置いたままにします。

## セットアップの順番

1. `brand/concept.md` `brand/voice.md` `brand/rules.md` の TODO を埋める
2. `venues/venues.md` に下見した会場を3件以上入れる
3. `/event-new` で1回作ってみて、手直しした差分をスキルに反映する
4. Notion の4つのDBを作る（Claude に依頼すれば作成できます）
