# カスタムスラッシュコマンド一覧

このリポジトリのイベント運営用コマンドを一覧で見せるだけのコマンドです。
何かを作成・変更することはしません。

## 手順

1. `.claude/skills/` 配下のディレクトリを列挙する（`event-list` 自身は除く）。
2. 各ディレクトリの `SKILL.md` のフロントマター（`description`）を読む。
3. コマンド名（ディレクトリ名を `/` 付きに変換）と、`description` の要点を1行に要約した表で出す。
   `CLAUDE.md` の「よく使うコマンド」表と齟齬が無いか、念のため見比べる。
4. `.claude/skills/` に無いが `CLAUDE.md` に載っているコマンド、逆に `.claude/skills/` にあるが
   `CLAUDE.md` に未掲載のコマンドがあれば、その旨を一言添える。

## 出さないもの

- 各コマンドの詳細な手順（知りたければ該当 `SKILL.md` を直接読むよう案内する）
- イベントデータそのもの（Notion・つなげーとへの問い合わせはしない）
