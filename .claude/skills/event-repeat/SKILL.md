# 既存イベントの再度作成

月4回のボードゲーム会など、**内容は同じで日付だけ変わる回**のためのコマンドです。
つなげーとと Notion に同じ内容を2回打ち込む作業をなくします。

**公開はしません。** 下書きを作って止まります。公開ボタンは人が押します。

作業の前に `docs/notion-event-rules.md` と `docs/tunagate-api.md` を読むこと。

## 手順

### 1. 元にするイベントを特定する

`TEST_Event_Projects_DB`（Notion MCP）から、`イベントタイプ` と直近の `開催予定期間` で候補を探す。
候補が複数あれば一覧で示して確認を取る。勝手に選ばない。

元ページの本文（`## イベント概要` と `## 募集本文`）とプロパティを読む。

### 2. 差分だけをまとめて1回で聞く

変わるのは基本的に日付と時刻だけ。それ以外の変更の有無を**1回にまとめて**聞く。

- 会場（変わるなら `Venues_DB` から候補を出す）
- 定員 / 参加費（早割の有無、販売期限）
- 募集タイトル

**会場の予約状況は必ず確認する。**
元イベントの会場・時間帯・利用料金を示したうえで「この会場・時間で予約は取れていますか？」と聞く。
**予約そのものは人の作業。**取れていなければそこで止まる。

不明な値は `TODO:` として残し、埋めた体で進めない。

### 3. Notion ページを作る

`TEST_Event_Projects_DB` に新規ページを作成する。**`ep_*` プロパティには触れない。**

| 項目 | 入れるもの |
|---|---|
| タイトル | `YYMM-種別_イベント名`（種別は元イベントから継承） |
| `開催年度` `開催月` `開催予定期間` `イベントタイプ` | 必須。1つでも欠けたら未完成 |
| `会場情報` | `Venues_DB` へのリレーション |
| `進捗状況` | **`企画・計画中`**（まだ つなげーと未作成） |
| `確定申告判定` | **`対象`** |
| `優先度` | `中` |
| `参加窓口` | 空のまま（手順6で入れる） |
| `参加者・関係者` `確定日時` `関連タスク` | **入れない** |

本文は `events/_template/notion-page.md` の形に従い、元ページから引き継いで日時・会場を差し替える。

- `## イベント概要` — `【募集タイトル】【メイン画像】【定員】【参加費】`
- `## 募集本文` — `brand/voice.md` のトンマナ、`brand/rules.md` の規約とキャンセルポリシー

### 4. 投げる前にチェックする

作った本文をファイルに書き出し、チェックを通す。

```
python3 scripts/tunagate/cli.py check --body-file <path> --with-draft-count
```

**1つでも `[中止]` が出たら、つなげーとには作成せず、内容を直してからやり直す。**
直せない理由があればユーザーに報告して止まる。

### 5. つなげーとに下書きを作る

```
python3 scripts/tunagate/cli.py create --body-file <path> --event-date <ISO8601>
```

チェックが通った場合だけ下書きが作られる。**公開はされない。**

`--dry-run` を付けると、送信せずにパラメータだけ確認できる。
初回や、内容に不安があるときは先に dry-run を挟む。

### 6. Notion に書き戻す

- 下書きのURLを `参加窓口` に入れる
- `進捗状況` を `企画・計画中` → **`進行中`** に変える

**途中で失敗したら Notion を書き換えずに止める。**中途半端な同期状態を作らない。

### 7. 告知文の下書き

`イベントタイプ` に 🍶日本酒 が入っている回は、Threads 用の投稿文を作る。
`brand/voice.md` のトンマナに従う。**投稿は人が行う。**

### 8. 最後に出すもの

- つなげーとの下書きURL
- Notion のページURL
- **人がやること**: ①下書きの内容確認 ②公開ボタン ③（日本酒なら）Threads投稿

## 守ること

- **公開（`publish`）は叩かない。**「公開して」と明示的に言われたときだけ実行する
- `ep_*` プロパティを読まない・書かない
- `進捗状況` を `完了` にしない。`完了` は確定申告の記入後に人が付ける
- 「恋活」「婚活」「出会い」を募集文・告知文に使わない
- 参加者の個人情報を書かない
- 金額・日付・人数を推測で確定しない
- 飲酒を伴う回は対象を20歳以上にする

## つまずきやすいところ

| 症状 | 原因 |
|---|---|
| 作成が 422 で落ちる | 下書きが10件に達している。不要な下書きを消す |
| 無料イベントとして作られた | `【参加費】` の表が無い。省略するとつなげーと側が無料プランを自動生成する |
| 画像でリクエスト全体が落ちる | Notion 添付の署名付きURLを使っている。失効するため恒久URLを置く |
| 404 が返る | 権限不足か不在。APIはこの2つを区別しない。「消えた」と誤判定しない |
