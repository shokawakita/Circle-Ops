# 月次サマリ

見る数字は3つだけです。細かいKPIは趣味の延長の規模では逆効果になります。

## 集計する3つ

1. **参加人数**（延べ / 実人数 / 初参加）
2. **リピート率**（前月までに参加した人のうち、今月も来た割合）
3. **粗利**（売上 − 原価。分配前と分配後の両方）

## 手順

1. `events/` の当月分の `pl.md` `retro.md` を読む
2. `finance/ledger.csv` から収支を集計する
3. Notion のイベントDBがあればそちらも突き合わせ、差異があれば指摘する
4. 前月比を出し、**伸びた／落ちた要因の仮説**を添える（数字だけ出しても意味がない）
5. 翌月の開催計画のたたき台を出す。会場は `venues/venues.md` から候補を出す

## レポートの形

```
## YYYY年M月

参加      延べ ◯名 / 実人数 ◯名 / 初参加 ◯名   （前月比 ±◯）
リピート率 ◯%                                （前月比 ±◯pt）
粗利      ◯円（分配後 ◯円）                   （前月比 ±◯）

### 効いたこと
### 効かなかったこと
### 翌月の計画（たたき台）
```

## 守ること

- 数字が悪い月を取り繕わない。原因の切り分けを優先する
- リピート率が落ちているときは、参加人数が伸びていても警告する（**最も重要な先行指標**）
- 3ヶ月連続で参加者が4人を下回ったら、形式の見直しを提案する
