# 週次SNSカレンダー

SNSは「毎日考える」から続かなくなります。週1回まとめて作り、投稿だけ手で出します。

## 手順

1. **前提を読む。** `brand/voice.md` のトンマナ、`brand/concept.md` の看板価値。
   `events/` から今週・来週の予定を拾う。

2. **今週の状況を確認する。** 告知したいイベント / 使える写真の有無 / 先週の開催実績。

3. **7日分の投稿案を作る。** 全部を告知にしない。目安は次の配分。

   | 種別 | 本数 | 内容 |
   |---|---|---|
   | 告知 | 2 | 次回イベントの募集。初出と締切前のリマインド |
   | レポート | 1〜2 | 前回の様子。参加者の顔が写らない構図を優先 |
   | 世界観 | 2 | 会場の下見、準備風景、主催者の考えていること |
   | 交流 | 1 | 質問・アンケート形式。コメントが付きやすいもの |

4. **各投稿に含めるもの**
   - Instagram: キャプション（冒頭2行で内容がわかること）、ハッシュタグ
   - X: 140字以内の短文
   - 投稿の曜日と時間帯の提案（理由も一言）

5. **ハッシュタグの組み立て**
   エリア系（#横浜 #新宿）/ 興味系（#ボードゲーム #カフェ巡り）/ 属性系（#社会人サークル）を混ぜる。
   同じ組み合わせを毎回使い回さない。

6. **Notion のコンテンツDB**があれば、投稿予定として登録する。

## 守ること

- 「恋活」「婚活」「出会い」をキャプション・ハッシュタグに使わない
- 参加者の顔が写る写真は、掲載可否を確認済みか必ず問い返す
- 煽り表現（「残りわずか」「今だけ」）を集客目的で使わない
- 参加者の本名・アカウントを許可なく載せない
