# イベント作成

## 手順

1. **前提を読む。** `brand/concept.md` `brand/voice.md` `brand/rules.md` `venues/venues.md` を必ず読む。
   トンマナと規約は毎回ここから引く。記憶で書かない。

2. **不足情報を確認する。** 次の6点が揃っているか確認し、足りないものだけをまとめて1回で聞く。
   開催日 / エリア・会場 / 企画内容 / 定員 / 参加費 / 主担当
   ユーザーが「任せる」と言った場合は、`venues/venues.md` と過去の `events/` から妥当な案を出して確認を取る。

3. **ディレクトリを作る。** `events/YYYY-MM-DD-slug/` に `_template/` を複製する。

4. **各ファイルを埋める。**

   - `plan.md` — 目的は1つに絞る。成功の定義は開催後にYES/NOで答えられる形にする
   - `pl.md` — 会場台帳の費用から原価を引き、**損益分岐人数を必ず算出する**
   - `recruit.md` — 募集文。下記の必須9項目をすべて含める
   - `script.md` — 90分テンプレを企画に合わせて調整。持ち物チェックリストも企画別に足す

5. **募集文の必須9項目**（1つでも欠けたら未完成）
   日時 / 場所（最寄駅まで）/ 定員 / 参加費と内訳 / 当日の流れ / 対象（年齢制限）/ 禁止事項 / キャンセルポリシー / 主催者の一言

6. **SNS告知文を作る。** Instagram のキャプションとハッシュタグ、X 用の短文を `recruit.md` の末尾に入れる。

7. **Notion に反映する。** Notion MCP が使える場合、イベントDBにページを作成する。
   DBがまだ無ければ作成を提案する。

## 守ること

- 「恋活」「婚活」「出会い」を募集文・告知文に使わない
- 参加者の個人情報を書かない
- 金額・日付・人数を推測で確定しない。不明なものは `TODO:` で残す
- 飲酒を伴う回は対象を20歳以上にする
- スポーツ・ウォーキング・遠出の企画では、**中止基準（雨天・気温）と保険の要否**を `plan.md` の懸念欄に必ず立てる

## 企画別の注意

| 企画 | 追加で確認すること |
|---|---|
| 鍋パーティ・調理あり | 食材費は実費割り勘、調理は参加者全員で。食物アレルギーを申込時に確認 |
| カフェ巡り・飲食店 | 団体利用の可否と撮影可否を店に事前確認 |
| 遠出・宿泊 | 現地集合・現地解散にする。宿泊は各自予約（手配して手数料を取らない） |
| スポーツ大会 | 施設予約・保険・体力差への配慮 |
