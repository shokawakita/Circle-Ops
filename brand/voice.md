# トンマナ

## 基本

- 一人称: TODO:（「私たち」／「運営」／サークル名）
- 語尾: です・ます調。フランクだが雑にしない
- 一文は40〜60字を目安に短く切る
- 参加者を「お客様」とも「メンバー様」とも呼ばない。「参加者のみなさん」

## 使う言葉

- 「はじめまして同士」「ゆるく」「気軽に」「ひとりでも大丈夫」
- 「一緒に」「みんなで」

## 使わない言葉

| NG | 理由 |
|---|---|
| 恋活 / 婚活 / 出会い | コンセプト上の判断（`brand/concept.md` 参照） |
| 絶対に / 必ず / 100% | 断定は誇張になり、期待値も上げすぎる |
| 「意識の高い」「ハイスペック」 | 参加者を選別する響きになる |
| 「限定」「今だけ」を煽り目的で | 煽りの文体はコンセプトと合わない |
| 「〜させていただきます」の多用 | 距離が出る。「〜します」で十分 |

## 募集文に必ず入れる項目

1. 日時
2. 場所（最寄駅まで。詳細住所は申込後に案内）
3. 定員
4. 参加費と、その内訳
5. 当日の流れ
6. 対象（年齢制限を含む）
7. 禁止事項（`brand/rules.md` から）
8. キャンセルポリシー
9. 主催者からの一言
