# 企画: ポーカー初挑戦＆いつものボードゲーム会

- 開催日: 2026年11月1日（日）13:00〜17:00
- 会場: 氷川区民会館_集会室（東京都渋谷区東2丁目20-18・渋谷駅から徒歩15分／`venues/venues.md`）午後枠
- 定員: 10名（早割チケット4名＋参加チケット6名。つなげーと下書き `events/617916` の実際のチケット構成）
- 参加費: 早割1,200円（4名）／参加チケット1,500円（6名）。内訳は `pl.md` 参照
- 最低催行人数: 4名（つなげーと側の設定値）
- 主担当: 自分（ポーカーは主担当も初心者）
- 当日運営: ポーカー好きの知人1名にサポートに入ってもらう予定（チケット購入の要否は主催者が別途調整）

## この回の目的

いつものボードゲーム会の常連に、新しい遊びの選択肢として「ポーカー」を無理なく体験してもらう。
賭け事ではなくエンタメとしてのポーカーだと安心して参加できる場をつくる。

## 成功の定義

参加者のうちポーカー未経験者の半数以上が、体験後に「またやりたい」と言う、または次回のポーカー枠に興味を示す。

## 想定する参加者

- いつものボードゲーム会の常連（ポーカーは未経験〜ほぼ未経験が中心）
- 20〜30代中心（いつもの客層を想定）

## 懸念とその対策

| 懸念 | 対策 |
|---|---|
| 金銭を賭けていると誤解される（賭博と誤認されるリスク） | 募集文・当日説明の両方で「チップのみ・現金のやり取りなし」を明記する |
| 主担当自身もポーカー初心者で、進行が滞る可能性 | ポーカー好きの知人にサポートに入ってもらい、ルール説明・進行を任せられるようにする |
| ポーカー初心者が多く、ルール説明に時間がかかり進行が押す | 開始直後にルール説明の時間を確保し、簡易ルールシートを用意する。ボードゲーム時間と分離する |
| 友人から借りる予定のマット・チップが数量不足で、追加購入費が3,000円を超える | 開催前に友人へ数量を確認し、不足分のみ購入する。超えそうな場合は事前に見直す |
| 定員10名に対し、初回企画のため集客が伸びない可能性 | つなげーと側で最低催行人数4名を設定済み。早割チケット4名分の売上（4,800円）だけで原価4,400円を上回るため、赤字リスクは小さい |
